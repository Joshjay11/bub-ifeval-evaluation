What this tests

IFEval checks whether an AI follows clear rules, such as using a set number of words, including a required phrase, or returning a requested format. Following these rules helps people and software use an answer as intended.

A prompt passes only when all its checked instructions pass. Strict scoring checks the saved answer. Loose scoring also allows the reference scorer's permitted text adjustments. The saved answer itself does not change.

This is not an instruction-following failure. The request did not yield a valid response to score.

Token-limit completions

Six responses reached the frozen 2,048-token output limit. They were preserved and scored exactly as returned.

A token is a unit of text used by the model. Reaching the limit can cut an answer short and cause it to miss an instruction.

This is treated as a model/configuration outcome rather than an infrastructure failure. These responses were not retried or excluded.

Scorer variability

Repeated runs of the unchanged reference scorer differed slightly because some reference checks contain unseeded/random behavior.

In plain terms, some checks use randomness without a fixed starting point. Five scorer runs checked the same saved answers; no new model answers were generated.

Method / evidence discipline

  • Frozen benchmark inputs
  • Raw responses preserved before scoring
  • Zero retries or replacement generations
  • Operational failures kept separate from model failures
  • Reference strict and loose scoring
  • Repeated scorer diagnostics
  • Configuration and integrity hashes recorded
  • Private BUB material excluded from public export

Limitations

  • One of 541 requests produced no valid scorable response.
  • This is one run of one frozen BUB/model configuration, completed across three execution packages.
  • Scorer variability was observed.
  • Actual billed provider cost was unavailable.
  • The results do not establish performance on tasks outside IFEval.
