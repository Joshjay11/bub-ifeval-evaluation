# Production change: Bub Baseline V1

Quintessence was removed from production prompt assembly. Condition B became the production baseline following the Quintessence V1 ablation pilot.

Bub Baseline V1 assembles these components in order:

**COSMOLOGY -> SOUL -> Anti-Slop -> Theater Mode -> Media Instructions**

Production implementation: **PR #78**.

Production merge commit: **`2a76d43f6c45c2b49ccef07ebb4165f682cfe3c9`**.

These production identifiers and deployment details were supplied by the experiment owner. The sealed experiment report supplied the analytical recommendation to remove Quintessence; it was not itself a deployment record. This publication task does not change production or independently re-execute that deployment.

The decision reflects insufficient demonstrated incremental value from Quintessence and the preference for B's observed behavior. C did not materially rescue the principles through plain-English translation. D's strong conventional scores did not outweigh its undesirable behavioral tendencies, so D was not adopted wholesale.

The change is a reversible product choice based on a 12-case pilot, not a claim of statistically established superiority across tasks or models. Quintessence's original development for D6 is historical context; it does not prove why the later GLM-5.2 evaluation produced this result.

This document publishes component names and assembly order only. It intentionally omits the contents of COSMOLOGY, SOUL, Anti-Slop, Theater Mode, Media Instructions and Quintessence, as well as private implementation paths and repository links. The experiment's sealed evidence remains unchanged.
